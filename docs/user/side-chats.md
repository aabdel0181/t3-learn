# Side chats

When a lesson raises a question, highlight the part you want to understand and choose **Ask in side chat**. The side chat opens beside the lesson with the highlight and its context. Choose **Done** when you are finished; the side chat leaves a note that the next lesson message can use. Side chats can nest, so follow a question as far as you need.

## Settings

Open **Settings → Threads → Side chats** to choose the model for new side chats, change how they explain things, and attach skills. Skills are added when a side chat starts where its provider supports them; a few providers can only see the skill name.
